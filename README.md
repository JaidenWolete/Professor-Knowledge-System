Professor Knowledge Expert System

COSC 369 Midterm Project

Description:

This project is a knowledge-based expert system that uses:

- Python
- SWI-Prolog
- PySwip
- YAML
- Excel
- DOCX
- GitLab

The system reads data from multiple sources and converts the information into Prolog facts that can be queried by users.

Data Sources:

- YAML

Stores professor information:

- Name
- Office
- Email
- Specialty
- Excel Schedule

Stores:

- Course IDs
- Course Titles
- Professors
- Rooms
- Meeting Days
- Meeting Times
- Syllabus

Stores:

- Instructor Information
- Office Hours
- Course Information
- Weekly Topics

Project Structure:

- app/
- data/
- parser/
- prolog/

- README.md
- requirements.txt
- .gitlab-ci.yml
